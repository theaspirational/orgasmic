## Changed
- Generalized regenerate around descriptor lookup and `node.regenerate:<id>` supervisor leases. The artifact route delegates to the same regenerate path; generic node regenerate/submit routes and CLI verbs cover task, decision, and glossary nodes.
- Replaced hardcoded artifact regeneration assembly with descriptor-selected Prompt Studio compilation using `node.content`, `node.comments`, and `node.extra_prompt` slots. Added shipped task, decision, and glossary regenerate specs; artifact-generator v2 consumes the same slots.
- Made regenerate close-out type-agnostic through `node_kernel::consume_open_comments`, recording `CONSUMED_CIDS`; generic submit validates identity/required fields/state, replaces node.org, bumps `VERSION`, and never enters task dispatch.
- Kept artifact-specific submit, MDX archive, state, launch-address, and journal behavior while moving its supervisor lease to the node key.
