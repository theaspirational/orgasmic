exit into the host stamp (or equivalent). Out of scope for this fix; M-1's
standing invariant is the FAIL_COUNT>0 path, which now agrees.

## Minimum window

`SYSPOLICYD_RATE_MIN_WALL_S=10`. Floor of the brief's 10–30 s band: long enough
to refuse the reviewer probes (`wall_s=1` / `wall_s=3` → `unknown (window too
short to judge)`, neither calm nor DEGRADED), short enough that a scoped crate
run still judges. Confirmed by the real scoped run below (`wall_s=11`, calm).

Sub-second clamp-to-1 removed so a fractional window is not under-reported as
rate-over-1s.

## Stamp with no `wall_s`
