# TASK-AJP4A implementation handoff

## Changed

- Replaced daemon-boot whole-board materialization with eager board/home-safety catalog bootstrap. Every registered root is watched before bind, while each project remains explicitly `unloaded` until first project access.
- Added index-owned `unloaded`/`loading`/`ready`/`failed` diagnostics and a single-flight `ensure_project_loaded` coordinator boundary with concurrent coalescing, retry after failure, generation publication, watcher/mutation convergence, and board-change invalidation.
- Split recursive source-marker and artifact summary work into separate lazy per-project projections. Core Tasks loading now reads operational `.orgasmic` task/graph/tx/integrity state without traversing repository source trees.
- Made catalog/list/status/UI routing catalog-driven so every registration is navigable before materialization. Project views still trigger correctness through the existing project request.
- Centralized project authorization before filesystem loading. Explicit task/marker requests load one authorized project; legacy project-less task and marker lookup loads only admin-all or the caller's authorized projects. Added member regression tests proving an unauthorized project remains unloaded.
- Made parse-error coverage require both core and marker projections before reporting `complete`, with explicit marker counts/unloaded IDs in `x-orgasmic-project-coverage`.
- Fixed changed board registrations by comparing the full prior `BoardEntry`, removing stale repository metadata, unwatching an old path, attaching the current path, and forcing a current-root repository probe. Added index and live watcher path-change regressions.
- Preserved the existing project-local marker-error invalidation path unchanged after the manager correction; no failing out-of-root regression justified churn there.
