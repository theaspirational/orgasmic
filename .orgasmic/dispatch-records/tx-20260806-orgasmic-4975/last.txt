### Exit code
- **4 = INCONCLUSIVE — re-run when calm** (next free after 0/1/2/3).
- A degraded host makes the whole run inconclusive **either way** — including
  a green suite (the property people forget).

## C — load-sensitivity interlock

- Unregistered + isolation-green + **host degraded** → `LOAD-SENSITIVE`
  (not a registry excuse; no owner).
- Unregistered + isolation-green + **host calm** → still `REAL`.
- Failing alone → always `REAL`, regardless of load.
- LOAD-SENSITIVE labels on a calm host → `Interlock broken` / exit 1
  (unreachable when the gate holds).
- **Did not** register the ten unregistered 2026-08-02 failures.
- Proof: `verify/TASK-STWVB/` — injection drops the `HOST_DEGRADED` gate;
  `orgasmic verify TASK-STWVB` PASS (red-then-green).
