** Context
The project must decide whether v0.0.1 includes approval queues, permission tiers, or tool whitelists for the manager. An approval queue makes changes safer but greatly enlarges the v0.0.1 surface; a tool whitelist duplicates host-agent permission systems.
** Decision
No orgasmic permission tiers in v0.0.1. Oversight comes from prompt discipline, =manager.action= tx entries, and visible UI notifications; the manager uses host tools and the orgasmic CLI directly.
** Consequences
Safety is explicit auditability and review, not a partial sandbox duplicated inside orgasmic.
