** Context
Four secondary pages need their shapes locked. Adding per-page graphs is redundant with the cross-domain Graph.
** Decision
Use per-surface list patterns. Glossary: list + modal only, no graph, IDs hidden (canonical name is the primary key); rows show bold name + first sentence + relates-to chip; modal shows definition + avoid list + relates-to chips (back-stack) + source. ADR: list + modal mirroring Decisions; rows show adr_NNN mono + title + status pill + source dec_NNN chip; modal shows body markdown + "Generated from dec_NNN" + source link; top-right Regenerate ADRs (direct POST). Snapshots: list + actions, no modal; rows show snap ID + ts + label + created-by + Restore/Copy actions; top-right Take snapshot (direct POST). Activity: day-grouped chronological feed with runs clustered as expandable cards and a Type/Actor/Date/Task filter bar.
** Consequences
Each secondary surface gets a fit-for-purpose list pattern without redundant per-page graphs; the snapshot diff preview is deferred. The ADR and Snapshots pages were later removed (the Glossary and Activity list pages were kept).
