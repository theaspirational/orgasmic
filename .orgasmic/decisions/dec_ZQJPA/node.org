** Context
The write path is fail-open for agents today: entry.org's write rules fall back to "match existing Org structure" when the CLI/daemon check fails; =conventions/no-skill-installed.org= grants direct goal/handoff writes; the scaffold bootstrap task states "you do not need the daemon to run this"; =/orgasmic init= scaffolds with plain file writes. Hand-editing also remains routine for the MANAGER because half the write surface is missing: =task update --state/--property= returns 501 (citing TASK-TQQQR, long DONE — orphaned debt), there is no =task create= verb, goal lifecycle has no verb (TASK-G9KCN). The round-4 critique (§6) called the fail-open bootstrap a baseline-poisoning compromise; dec_SSJVDc rejected fail-fast with detection-over-prohibition at the time. The lints since proved both halves: the phantom-heading lint catches hand-edit drift (its first catch was our own scaffold seed), and every hand-edit burst is unaudited writer-loop bypass.
** Decision
(a) /The daemon (driven through the CLI) is the only org-state write path for agents./ Managers and workers never hand-edit =.orgasmic/*.org= once the write surface is complete; every agent mutation rides the single writer loop, the structural-invariance guard, and OCC. The human/operator lane is unchanged — dec_MK7AH detect-and-reconcile governs human hand-edits; it is not a license for agents. (b) /Install/init simplifies to runtime-first:/ one canonical path — install CLI+daemon, then init and bootstrap THROUGH the runtime. The no-skill / CLI-absent editing fallbacks are retired; a missing runtime routes to install instructions (fail-fast), not to hand-editing. Daemon-free init is no longer a product requirement (reverses that premise of dec_SSJVDc). (c) /Phasing:/ the doctrine flips per surface as verbs land (TASK-G9KCN: goal/tx/state-flip; TASK-NP5H6: create/property/body). Until then manager direct-edit remains the documented interim mechanism — prohibiting edits before the verbs exist would deadlock state maintenance. Detection lints (TASK-HC7PW phantom headings, TASK-QRD3Y identity) stay as the standing safety net for the human lane.
