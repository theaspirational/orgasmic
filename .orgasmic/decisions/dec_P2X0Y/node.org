** Context
The user supplied ClickUp screenshots showing a large centered task modal with internal side rails, not a narrow side drawer or route-only page. A right-side drawer cannot host the three-column layout; a dedicated full-page route loses kanban context behind a route change.
** Decision
Use a large centered shadcn Dialog (~90vw × ~90vh on desktop) with three internal columns: a collapsible subtask sidebar (parent + flat list of children + "+ Add Subtask"), a center pane (breadcrumb + nav arrows + title + status pill + property strip + description + inline subtasks section + later sections), and a right activity rail with a comments composer at the bottom. On mobile (≤768px) it becomes a full-screen Sheet with single-column stacked content, the subtask sidebar as a tab, and activity as a peekable bottom sheet.
** Consequences
Users keep list or kanban context behind the modal while getting room for detail, subtasks, and activity. Day-1 sections are properties · description · subtasks · activity log, with Acceptance Criteria, Evidence, and Worklog as later collapsed sections.
