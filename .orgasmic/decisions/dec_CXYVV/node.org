* dec_CXYVV What fields belong in the task property strip, and when do they lock?    :ui-tasks:
:PROPERTIES:
:ID:            dec_CXYVV
:DECIDED_AT:    [2026-05-23 Sat 15:15]
:SOURCE:        archive/2026-05-23_ui-redesign/grill.md
:PARENT:        dec_P2X0Y
:END:
** Context
With ownership auto-derived (dec_CX17K), the property strip's field set differs from ClickUp's and its rows must lock when an agent owns the task. Including manual Owner and Agent-template pickers would contradict dec_CX17K/dec_JW9TJ.
** Decision
The strip carries: Status (popover to valid transitions; locked when agent-owned), Owner (display only), Kind (display only — changing breaks run history), Priority (popover P0..P3; locked), Depends-on chips (task picker; locked), Blocked-by chips (task picker; locked), Implements chips (display only — set by planner/architector), Tags (combobox; locked), and Last-updated (display, mono). Dates and time estimate are deferred; the agent template is removed from the strip (auto per dec_JW9TJ).
** Consequences
The strip reflects auto-ownership and locks editable rows when agent-owned, while comments stay writable.
