* dec_HYD58 How should the sidebar primary navigation be structured?    :ui-ia:
:PROPERTIES:
:ID:            dec_HYD58

:SOURCE:        archive/2026-05-23_ui-redesign/grill.md

** Context
With Board demoted to a switcher, the primary nav needs a new ordering. The user requested four primary items — Decisions, Architecture, Tasks, Glossary — with the rest behind a spoiler, and explicitly wanted Manager off the nav.
** Decision
Sidebar shows the project selector, then Decisions / Architecture / Tasks / Glossary as primary, then a "Show more" disclosure containing ADR / Graph / Snapshots / Activity. The Manager surface lives only in the bottom popover (dec_DTJPD); the Org viewer is removed from nav; Status and Settings live in the top header as LED and gear icons (dec_H9P38).
** Consequences
The nav stays focused on the four primary work surfaces and is easy to extend through the spoiler.
