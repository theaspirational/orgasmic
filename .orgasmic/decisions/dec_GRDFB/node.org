* dec_GRDFB How should shipped, optional, and user content be layered and overridden?    :shipped-content:

:END:
** Context
Agent templates, prompt templates, and skills need a consistent lifecycle. Bundling everything makes shipped content noisy and hard to curate, while a runtime-marketplace-first model trades core product delivery for ecosystem reach too early.
** Decision
Use a three-tier content model: defaults ship with orgasmic, optional content is opt-in, hub content can be installed by URL, and user files override shipped files. The same shipped/optional/hub and override model applies to skills, agent templates, and prompts.
** Consequences
Discovery stays curated and customization stays predictable through a single override rule.
