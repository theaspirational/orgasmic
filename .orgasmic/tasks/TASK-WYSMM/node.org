* DONE TASK-WYSMM Mobile: selection-comment quote stuck on first word; extend-selection never updates the composer :ui:bug:
:PROPERTIES:
:ID: TASK-WYSMM
:END:

On mobile browsers, long-press selects one word and touchend opens the inline comment composer quoting only that word. Dragging the native selection handles to extend the selection never updates the quote: handle drags do not dispatch pointerup/touchend to the page (only document.selectionchange fires), and ArtifactView captures the anchor exactly once on pointerup/touchend/keyup. Fix: keep the captured anchor in sync via a debounced document selectionchange listener while the composer is eligible, re-capturing when the selection is non-collapsed inside the artifact body and preserving the existing quote when the selection collapses (e.g. focusing the textarea).
