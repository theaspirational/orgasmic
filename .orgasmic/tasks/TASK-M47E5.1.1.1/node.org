*The adapter must not trust its input.* Require the artifact dir to be a STRICT,
shape-validated child of the resolved dispatch root — preferably
=resolved_artifact_dir.parent() == resolved_dispatch_root=, which matches the

Neither alone is sufficient: the adapter fix is the security boundary and must
hold against any input, while the CLI fix removes the only known route to that
input and is cheap.

=== The judgement worth carrying forward

Four rounds, four reviews, and the recurring failure is not in the production
reasoning — it is that each round's TEST proved something adjacent to the claim
rather than the claim. The widening survived because the matrix checked sibling
worktrees and not sibling stems; the input gap survived because the test
hard-coded a well-formed directory; this gap survives because the test does
production's arithmetic for it.

The remedy adopted for round 5 is a mutation-shaped acceptance criterion: the
test must FAIL if production derives the grandparent, the file itself, or =None=.
Naming the mutations a test must catch is stronger than naming the value it
should assert, and every round of this chain would have been caught by it.
