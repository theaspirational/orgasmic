** B1 — HIGH — a fixed threshold on a quantity that grows with run duration
=scripts/run-tests.sh:95=; window at =:591-598=.

=SYSPOLICYD_CPU_DEGRADED=100.0= is an ABSOLUTE bound on cumulative CPU seconds,

   =:591-598=: =HOST_BEFORE= is taken, then =cargo test= runs (which BUILDS),
   then =HOST_AFTER=. Every freshly linked rustc output is a new Mach-O that

   =test_fixtures.rs:3-7=. A cold build IS a scan storm, and it is charged to
   the run's own degradation score.

   reviewer's +4.52s / 0.0753 s/s / ~22min almost exactly. Two independent
   measurements agree.

   line is crossed in roughly TWO MINUTES of suite execution.

The threshold was calibrated on the ONE run whose delta happened to land under
