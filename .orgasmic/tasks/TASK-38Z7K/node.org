** Description
Source: vscode-orsl manager letter 2026-08-22 (operator-forwarded, 40 dispatches over 4 days, orgasmic 0.0.18). Item 16. The ws driver reports pid=0, so dispatch-status shows `[pid-gone]` on every live ws run; the manager's monitor fired false DONEs until it keyed on [reported]/[run-gone] only.
** Expected
A driver that cannot report a pid omits the flag rather than setting it.
** Acceptance
Fixture: live ws run → no `[pid-gone]`; stdio run with dead pid → flag present.
** Resolution
5033cce: dispatch_health treats pid 0 as unknown; pid_flag() prints nothing when no pid is known, [pid-alive]/[pid-gone] only with a real pid. Covered by test unknown_pid_prints_no_flag_and_zero_counts_as_unknown.
