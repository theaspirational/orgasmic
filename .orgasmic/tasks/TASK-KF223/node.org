** Description

=STATUS_SPINNER_GLYPHS= now holds eight glyphs. Six are extracted from the
installed claude binary and are covered by
=status_spinner_glyphs_cover_the_installed_claude_frame_set=. Two are NOT:

- =U+25CF= — claude, from a live pane capture. The binarys frame array does not
  contain it, so the guard cannot check it. The TASK-4CSMY.2 author noted ~10
  other =U+25CF= sites in the binary and judged that chasing which code path
  paints it was out of scope for a false-kill fix.
- =U+25E6= — codex, from the round-3 reviewers live pane capture. Never
  extracted from any binary.

Neither is a defect today: both have real measured live-pane provenance, and
they are in the table for good reason. The gap is that if either harness changes
the ROLE of that glyph — from a status row to a transcript bullet — nothing
notices, and the failure direction flips to a false RESCUE: an at-rest pane whose
transcript starts with that glyph would be classified Working and survive to the
four-hour ceiling.

That is exactly the defect class TASK-JQ8AV.1 and TASK-4CSMY.1 were both raised
to close, surviving in the two places the new audit cannot reach.

** Work

- Trace the =U+25CF= paint path in the claude binary and, if it is extractable,
  fold it into the same guard.
- Decide how the codex glyph gets refreshed — a periodic re-capture under a named
  task, or extraction from the codex binary if its status row is reachable the
  same way. Note the round-3 reviewer captured it live from a real codex pane, so
  a repeatable capture recipe is feasible; measuring it costs a codex run, not a
  billed claude run.
- If neither is extractable, say so in the table comment next to those two
  entries, so the next reader knows which glyphs are audited and which are
  trusted.

** Acceptance

- Every entry in =STATUS_SPINNER_GLYPHS= is either machine-audited against its
  harness or explicitly annotated as capture-only with its capture date.
- No regression to the false-kill direction: a real live status row must still
  be recognised.
