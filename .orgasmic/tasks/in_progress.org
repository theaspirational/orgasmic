=== THE THIRD NARROW CHECK IN ONE STAGE — the real lesson

Round 1: the manager grepped =arch:= and missed the =@arch= prefix entirely.

=^\s*(//|#)\s+@arch(\s|$)= — *anchored to the comment prefix, therefore blind to

The pattern is not carelessness about greps. It is *writing checks shaped like the

retired syntax survives". The instrument for that is a bare =@arch= search across
the tree.

: @arch anywhere                       -> 0
: (//|#) arch: prefixes                -> 0
: architecture drift / architecture_drift -> 0
: orgasmic:arch_ markers               -> 60 (unchanged)

*Verify the claim with the broadest instrument, then narrow only to explain
failures.*
