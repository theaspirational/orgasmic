Grilled with owner 2026-08-22; decisions (a)–(c) plus the migrator's contract. Facts: 562 done + 20 cancelled tasks; 23 of the 46 DEPENDS_ON/IMPLEMENTS/… refs on live tasks point into them and 68 done ids are named in decisions/glossary, so old ids must resolve natively; every state file and project.org already carry #+orgasmic_version: 1.

(b) The activity projection reads old tx/ + new journals forever; tx/ is a read-only archive, never backfilled.
(c) Cut-over marker: bump #+orgasmic_version to 2 on project.org as a label only. Owner (2026-08-22): there is one user of orgasmic today, so NO backward-compatibility layer — the daemon does not detect or refuse a v1 layout and keeps no v1 read path; the migrator is run once per project and the old readers are deleted in the same change.
