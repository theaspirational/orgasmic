** Description
Every TASK-K9WWM review round serialized the same manager ceremony: wait for report, verify the worker commit, merge or bind the reviewed ref, close the implementer dispatch, move lifecycle state, commit daemon-written ledger state, choose an independent harness, compile a reviewer brief, and start review. TASK-P9T4N owns multi-tx close atomicity, TASK-3HR8R owns invisible in-review tasks, and TASK-GCTMA owns dirty refs workers cannot see. None owns orchestration of the complete handoff.

Add a recoverable manager workflow that advances from a reported implementation to a reviewer dispatch using one explicit command or durable state machine. It must verify that the reviewed commit is reachable, preserve the independent-harness rule, never review an uncommitted tree, and be idempotent across disconnects. Intermediate states remain inspectable and individually recoverable.

** Acceptance
- One invocation performs or resumes the complete handoff and returns the implementation SHA, reviewed ref, close tx, lifecycle transition, reviewer run, harness, model, and effort.
- Disconnecting after each internal boundary converges without duplicate close or reviewer dispatch.
- Refusal cases for dirty, unreachable, or already-reviewed refs remain loud.
- A repeated four-round workflow demonstrates reduced handoff time without overlapping review against an unstable ref.
