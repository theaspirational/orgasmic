** READ THIS FIRST — WHAT THIS TASK IS AND IS NOT
This task does NOT fix the prune. It makes the prune UNREACHABLE, so that manager
discipline stops being the only thing standing between this machine and a delete
path that has now failed two independent reviews with data-loss findings.

The redesign is TASK-RMA18. Do not do it here.

** Why this exists — a manager ruling
=orgasmic manager worktree-prune= has been reviewed twice and rejected twice, six
BLOCK SHIP findings between them, every one on the destructive path. It is
currently harmless for exactly ONE reason: the installed runtime predates the verb.

That coupling is now actively harmful, and that is the point of this task. THE
REINSTALL IS BLOCKED BY IT — and two GOOD changes are waiting on that reinstall
(the TASK-YN5FJ review gate, the TASK-M47E5 relocation), so the pressure to
reinstall keeps rising while the thing preventing it is a sentence in a handoff.
A protection that lives in a document is not a protection.

Make the verb refuse by CONSTRUCTION. Then the reinstall can happen, the two good
changes go live, and TASK-RMA18 can take the time a delete path deserves.

** What to do
1. =orgasmic manager worktree-prune= exits with a clear refusal naming this task
   and TASK-RMA18, and reclaims NOTHING — no salvage, no removal, no
   =git worktree prune=. Including =--dry-run=: a dry run of a scanner that
   follows an ancestor symlink still walks and sizes directories it has no
   business touching.
2. The AUTOMATIC DETECTION appended to =dispatch-status= goes with it. It shares
   the same unsafe scan: =scan_managed_worktrees= follows an ancestor symlink and
   would report a victim directory as reclaimable, and =directory_bytes= would
   walk it. Detection is read-only, so this is lower risk than the verb — but it is
   the same defect and it should not be advertising reclaimable trees it cannot
   correctly identify.
3. Do NOT delete the implementation. TASK-RMA18 starts from it, and the two review
   reports are the most valuable thing about it. Gate at the entry points.
4. The RELOCATION half is untouched and must stay green, including
   =dispatch_close_still_salvages_and_removes_an_old_path_worktree= and the
   dry-run path assertions.
