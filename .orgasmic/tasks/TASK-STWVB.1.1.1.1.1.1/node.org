** F-6 — LOW — the one parser dependency whose breakage fails GREEN
=scripts/run-tests.sh:850,855=. *This is the item worth taking; the other two are
optional.*

The crash detector rests on four cargo string shapes. THREE FAIL LOUDLY: if
=^[ \t]+Running …(bin)= or =^[ \t]+Doc-tests = breaks, every target's matchbin
becomes =?=, nothing can claim, and every failing target becomes a crash — a
false RED. If =Caused by:= / =process didn't exit successfully= breaks it costs a
display line only, which is exactly what unioning by identity bought.

ONE FAILS SILENTLY, GREEN-WARD: =^error: [a-z]+ failed, to rerun pass `= at
=:855=. If a future cargo rewords it, =TARGETS_TSV= is empty, =CRASH_COUNT= is 0,
the =CRASHED= section vanishes, and the only surviving witness is exit 101 —
which arm 7's =FAIL_COUNT= guard swallows the moment one registered flake fires.
*That is R-1's exact shape, re-armed by a cargo upgrade rather than by an edit.*

MEASURED (reviewer, cargo 1.94.1): cargo emits an INDEPENDENT second count of
failing targets, for N=1 as well as N>1:
#+begin_example
error: test failed, to rerun pass `--lib`
error: 1 target failed:
    `--lib`
#+end_example

*Fix:* cross-check. =grep -E '^error: [0-9]+ targets? failed:'= yields a target
count parsed from a DIFFERENT sentence; if it disagrees with =TARGETS_FAILED=,
the parser has drifted — RED with its own line. One grep, and it converts the
single green-ward dependency into a loud one. The summary block is emitted under
=--no-fail-fast=, which =run-tests.sh= always passes.
