** Question
One mint, many prefixes: keep existing styles (TASK-XXXXX, dec_XXXXX, term_...) or normalize? How are dir names derived from ids, and what does the mint need to become type-aware?
** Resolution
Grilled with owner 2026-08-22; three decisions. Facts: mint_node_id(class) = prefix + 5-char Crockford stem with no collision check; artifacts already use the id verbatim as the dir name; dotted subtask ids exist (TASK-AP971.11); 6k tx entries and every prose doc reference the current prefixes.
1. Prefixes: keep TASK-, dec_, term_, ART- verbatim; new types declare their own prefix in the descriptor (.2). No normalization.
2. Dir name = id verbatim; dotted subtask ids are flat sibling dirs (tasks/TASK-AP971.11/), no nesting. Crockford is uppercase, so case-insensitive disks are safe.
3. Type-aware mint: mint_node_id(descriptor) keeps the 5-char stem; uniqueness = mkdir of the node dir (atomic; collision fails → retry). No id registry.
