** Description
=.orgasmic/tmp/sessions/= grows without bound (1.1G / 535 files in 2.5 months on the orgasmic ledger). =run history compact= reclaims only rendered-TUI payload and treats structured session JSONLs as never-auto-cleaned authority. Operator precedent set 2026-08-28: delete session JSONLs older than 14 days (untouched-mtime), never files held open by a live run.

Design: a daemon housekeeping pass (or =run history= verb) that deletes terminal runs' session files past a configurable age (default 14d), skipping non-terminal runs and open handles. Promoted dispatch evidence (evidence.json, TASK-W97C8) keeps counts/pointers, so the record survives the raw file; =session.status= correctly reports =missing= with a reason afterwards.

** Acceptance
- Configurable age threshold, default 14 days; never touches non-terminal runs or open files.
- Runs as explicit verb or opt-in housekeeping; a dry-run mode reports files+bytes first.
- evidence.json for already-closed dispatches unaffected; a post-deletion close of an old run reports missing-with-reason, not an error.
