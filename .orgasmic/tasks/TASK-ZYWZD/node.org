Filed 2026-07-28. `orgasmic node body set` replaces only the free prose between
the property drawer and the first nested heading. A body containing `**`
sub-headings is silently truncated at the first one — TASK-ATAXN was filed with
300 of its 3959 characters and nobody was told. The read side compounds it:
nested `**` sections are NOT returned in the JSON `description` field, so the
loss is invisible through the same surface that caused it. A write verb that
can drop 92% of its payload and report success is the single worst surface in
the CLI.

=== The principle (shared with TASK-HQ970, defect 2)

A writer must not commit what it cannot read back. TASK-HQ970 states it for
`tx record` (re-parse before reporting success); this task applies the same
round-trip guarantee to the node body surface. If the fix grows shared
machinery (compose -> re-parse -> diff-against-intent -> refuse on loss), use
it for both.

=== Work

1. WRITE: `node body set` must either persist the full submitted body
   (including nested `**` headings, correctly re-depthed under the task
   heading) or REFUSE, naming exactly what would be lost ("body contains 3
   nested headings starting at '** The gap'; this verb replaces prose only —
   use ... or restructure with ==="). Never a silent partial write. Same audit
   for `node body append` and any sibling that composes org content.
2. READ: `task get` / `node` reads must expose the full body, or explicitly
   mark elision ("+ 3 nested sections not shown") — never present a truncated
   body as complete. Pick and record one; full exposure preferred.
3. Post-write verification: after composing the new file content, re-parse and
   assert the submitted body round-trips before the write is committed
   (mirrors HQ970's acceptance "a write that would not round-trip is rejected
   rather than committed").

=== Acceptance

- Setting a body containing `** Section` either persists it fully (verified by
  reading the raw org node) or errors naming the offending heading — proven
  both ways in tests.
- The ATAXN shape is the regression fixture: a ~4000-char body with three `**`
  sections survives set + get with zero loss, or is refused up front.
- No silent partial write remains on any `node body` verb (enumerate them in
  the report).
- Injection proof per project standard: restore the truncating behavior, show
  the round-trip test red with output, restore the fix, green.

=== Non-goals

- Do not implement TASK-HQ970 (tx record validation) here; share machinery if
  natural, cross-reference regardless.
- Do not redesign the org body/section model; make the existing surface honest
  about it.
